# Quiz-de-conhecimentos

📘 Sobre o Projeto: Este projeto é um quiz interativo de conhecimentos gerais, desenvolvido com foco em simplicidade, interatividade e visual moderno. O objetivo é testar o conhecimento do usuário por meio de perguntas de múltipla escolha, oferecendo feedback imediato e uma experiência divertida. 🧠 Funcionalidades

• Exibição de perguntas com múltiplas opções • Verificação automática de respostas • Feedback visual com ícones de ✅ acerto e ❌ erro • Pontuação final ao término do quiz • Botão para reiniciar e jogar novamente • Animações suaves entre perguntas • Layout responsivo para funcionar bem em celulares e tablets

🛠️ Tecnologias Utilizadas

• HTML5: estrutura da página • CSS3: estilização, cores vibrantes e responsividade • JavaScript: lógica do quiz, controle de perguntas e pontuação

📱 Experiência de Usuário

O quiz foi pensado para ter uma interface amigável, com botões grandes, emojis, cores vivas e transições suaves. Tudo isso para tornar o aprendizado mais leve e divertido.

🚀 Como Executar

Clone o repositório: git clone https://github.com/bbb8bbb/quiz-interativo.git
Abra o arquivo no navegador
Responda às perguntas e veja seu resultado! 🌐 Publicação Este projeto pode ser acessado online via GitHub Pages (se ativado nas configurações do repositório).
